# Staff access and Super Admin

Customer signup grants only the Customer role. Staff and logistics partners choose their category during signup. Existing customer accounts can request staff access from their portal. The database stores the choice as a pending application; it never grants the requested role from signup metadata. The applicant must confirm their email before approval. A Super Admin can approve or reject applications, link a Partner applicant to an active partner company, and revoke staff roles from the access-control page. A revoked user may request review again, but receives no access without another approval. Role checks use the database on every request, so revocation takes effect for existing sessions without waiting for a new login.

Logistics Partner applicants must confirm their email, sign in, and upload either a NIN document or CAC registration document (PDF or image, up to 5 MB) from the pending-access screen. The file goes to a private Supabase Storage bucket; only its owner and a Super Admin can open the submitted file. The Super Admin page shows the document type and opens a short-lived viewing link. Database approval refuses a Partner application without a submitted document, even if the front-end check is bypassed. Existing customers applying for Partner access follow the same upload step. Reapplications require a fresh document.

The two protected Super Admin addresses are `admin@gohezohservices.org` and `Info@gohezohservices.org`. Super Admin accounts are created through a server-side Supabase invitation, with the invite redirected to `https://gohezoh-services.vercel.app/?setup=1`. The invite recipient sets their own password on that page. No administrator password or service key belongs in browser code or this repository.

Supabase Auth's Site URL is `https://gohezoh-services.vercel.app/`. The hosted project's redirect allow-list includes the Vercel site and localhost:5173 for local development. The confirmation and invite templates use `{{ .ConfirmationURL }}`, which carries the configured redirect. `supabase/config.toml` mirrors these URL settings for local development.
